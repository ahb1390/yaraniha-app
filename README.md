# Yaraniha Desktop Application 🚀

اپلیکیشن دسکتاپ **Yaraniha** بر پایه الکترون (Electron) و کپاسیتور (Capacitor) توسعه یافته است. این برنامه به صورت هوشمند وضعیت اتصال به اینترنت را بررسی می‌کند و در صورت قطعی، به حالت آفلاین سوییچ می‌شود. خروجی‌های نهایی به صورت خودکار در بخش Releases گیت‌هاب منتشر می‌شوند.

## ✨ ویژگی‌های کلیدی
- **تشخیص هوشمند آنلاین/آفلاین:** بررسی خودکار اتصال و سوییچ آنی بین وب‌سایت و صفحه آفلاین.
- **مدیریت کش پیشرفته:** غیرفعال کردن کش HTTP و استفاده از Cache Buster برای دریافت همیشه آخرین نسخه سایت.
- **خروجی چندپلتفرمی:** تولید خودکار نصبی و پرتیبل برای ویندوز، لینوکس (deb, rpm, AppImage) و مک (dmg, zip).
- **انتشار خودکار:** آپلود مستقیم فایل‌های بیلد شده در GitHub Releases بدون نیاز به تگ‌گذاری دستی.
- **پیکربندی محیطی:** قابلیت سوییچ سریع URL سرور از طریق فایل `.env` بدون دستکاری کدها.
